# Одна гиря — техніка і програма

Український навчальний довідник: 18 вправ з безкоштовними відео, розбір наданої програми ONE KETTLEBELL та окрема адаптація тренувань на три дні.

Відео належать зазначеним авторам і відтворюються з YouTube. Джерела та уточнення доступні всередині додатка. Позначки виконання зберігаються лише у браузері відвідувача.
